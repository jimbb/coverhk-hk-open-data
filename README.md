# Hong Kong MPF & VHIS Open Data (CoverHK)

Clean, machine-readable CSV and JSON datasets synced directly from official Hong Kong statutory portals and maintained by **[CoverHK](https://coverhk.com)**.

## Datasets

| File | Records | Primary Official Source | Last Verified | Interactive Explorer |
| :--- | ---: | :--- | :--- | :--- |
| `hk-mpf-funds.csv` / `.json` | 451 MPF funds (as of 2026-10-31) | MPFA MPF Fund Platform (`mfp.mpfa.org.hk`) | 2026-11-19 | [CoverHK MPF Explorer](https://coverhk.com/en/mpf) |
| `hk-vhis-plans.csv` / `.json` | 30 VHIS plans (Age 25–70 std rates) | Health Bureau VHIS Office (`vhis.gov.hk`) | 2026-11-23 | [CoverHK VHIS Matrix](https://coverhk.com/en/vhis) |
